Python Demo

קריאה אמיתית למודל

import os
from google import genai

client = genai.Client(
    api_key=os.environ["GEMINI_API_KEY"]
)

response = client.models.generate_content(
    model="gemini-flash-latest",
    contents="Explain what an SSH brute-force attack is."
)
print(response.text)
דוגמת Python — לא מבוצעת במצגת
Client מגדיר גישה לשירות; model בוחר מודל; contents מכיל את הבקשה; response.text קורא את תשובת הטקסט. זוהי קריאה בפועל רק כאשר מריצים Python עם מפתח פעיל וחיבור לרשת.

JSON Schema + Validation
קוד Python עם פלט מובנה
import os, json
from google import genai
from google.genai import types
from pydantic import BaseModel, Field

class SecurityAnalysis(BaseModel):
    is_suspicious: bool
    attack_type: str
    urgency_level: int = Field(ge=1, le=10)
    explanation: str

event = {"service": "SSH", "failed_logins": 15,
         "policy_max_attempts": 3, "hour": "03:30"}
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])
prompt = ("Analyze this simulated network event. "
          "Use only given evidence; state uncertainty.\
"
          + json.dumps(event))
response = client.models.generate_content(
    model="gemini-flash-latest",
    contents=prompt,
    config=types.GenerateContentConfig(
        response_mime_type="application/json",
        response_schema=SecurityAnalysis,
    ),
)
analysis = SecurityAnalysis.model_validate_json(response.text)
print(analysis.model_dump())
SDK: google-genai. שימוש בפלט מובנה לפי התיעוד הרשמי; גם לאחר בדיקת סכמה חייבים לאמת מסקנות כנגד ראיות.

פרטיות, אבטחה ועלות
לפני ששולחים ל־API
🔒 פרטיות
לא שולחים סיסמאות, אסימונים, מזהים אישיים או לוגים רגישים ללא אישור ומדיניות.
💳 עלות
מגבילים אורך קלט, מספר קריאות ושימוש חוזר בתוצאות מתאימות.
🧯 בטיחות
טקסט לוג יכול להכיל Prompt Injection. מתייחסים אליו כמידע, לא כהוראות למודל.
לא כברירת מחדל. מסננים למידע הרלוונטי, מסירים פרטים מזהים היכן שניתן, בודקים מדיניות אבטחה וחוקיות, ומוודאים שהנתונים דרושים למטרה.


אמינות מקצועית
חומרת איום ≠ ביטחון המודל
Urgency = 9/10
עד כמה צריך להגיב במהירות, לפי הערכת המערכת.
Confidence = 0.95
ציון שהמודל מחזיר; אינו בהכרח הסתברות מכוילת.
במיני־פרויקט המצורף מוצעת מכפלה של 9 × 0.95 = 8.55 וקביעת קטגוריית איום.
זו היוריסטיקה אפשרית ולא מדד תקף ללא כיול ובדיקה. לפני שימוש מבצעי יש להגדיר מטריצת סיכונים, לאמת נתוני אמת ולבדוק False Positives ו־False Negatives.
