מה יש בתוך חבילה?

IP header20 bytes
UDP header8 bytes
Payloadנתוני החיישן

ב־IPv4 ללא אפשרויות וב־UDP: גודל חבילת IP = 20 + 8 + אורך Payload.

שימו לב: אין בדוגמה שכבת Ethernet. ה־PCAP מכיל חבילות IP גולמיות.

from scapy.all import IP, UDP, Raw

pkt = (
    IP(src="192.0.2.10", dst="198.51.100.20")
    / UDP(sport=40000, dport=5000)
    / Raw(load=b"M" * 132)
)
print(len(bytes(pkt)))  # 160

Scapy: הודעת מצב ב־TCP

from scapy.all import IP, TCP, Raw

pkt = (
    IP(src="192.0.2.10", dst="198.51.100.20")
    / TCP(sport=40001, dport=5001, flags="PA", seq=100)
    / Raw(load=b"S" * 80)
)
print(len(bytes(pkt)))  # 120

בדוגמה זו כותרות IPv4 ו־TCP הן 40 בתים יחד, ללא Options.

11 · קוד מורה

קובעים זמן ושומרים PCAP

from scapy.all import IP, UDP, Raw, wrpcap

packets = []
start = 1700000000.0
for i in range(5):
    p = IP(src="192.0.2.10", dst="198.51.100.20") / UDP(sport=40000, dport=5000) / Raw(load=b"M" * 132)
    p.time = start + i * 0.5
    packets.append(p)

wrpcap("greenhouse.pcap", packets)

הקוד יוצר 5 חבילות ושומר אותן לקובץ – ללא שידור לרשת.

🎓 הערות למורה · 5 דקות
