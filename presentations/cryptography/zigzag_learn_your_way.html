הצפנה — כתיבה במסלול וקריאה לפי שורות
מתחילים בשורה העליונה, מוסיפים תו לשורה הנוכחית ומשנים כיוון רק בקצוות. בסיום מחברים את השורות לפי הסדר.
INPUT: text, n
CREATE rails: n empty strings
SET row = 0, direction = 1
FOR each char in text:
    APPEND char to rails[row]
    IF row == 0: SET direction = 1
    ELSE IF row == n - 1: SET direction = -1
    SET row = row + direction
RETURN concatenation of rails from row 0 to n - 1
פענוח — שחזור החלוקה וקריאה במסלול
תחילה משחזרים את המסלול ללא התווים. סופרים ביקורים בכל שורה, חותכים את ההודעה בהתאם, ואז קוראים תו אחד בכל ביקור ומקדמים את אינדקס הקריאה של אותה שורה בלבד.
מושג / משתנהמשמעות
cipherההודעה המוצפנת.
countsמספר התווים בכל שורה.
start / endגבולות החיתוך במחרוזת המוצפנת; end אינו נכלל.
positionsאינדקס התו הבא לקריאה בכל שורה.
r / indexמספר השורה הנבחרת / אינדקס התו בתוכה.
resultההודעה המשוחזרת שנבנית בהדרגה.
INPUT: cipher, n
BUILD route using length(cipher) and n
CREATE counts: n zeros
FOR each r in route:
    INCREASE counts[r] by 1
SET start = 0
CREATE empty list rails
FOR each count in counts:
    SET end = start + count
    APPEND cipher[start:end] to rails
    SET start = end
CREATE positions: n zeros
SET result = empty string
FOR each r in route:
    SET index = positions[r]
    APPEND rails[r][index] to result
    INCREASE positions[r] by 1
RETURN result
route = [0, 1, 2, 1, 0, 1, 2, 1, 0, 1]
counts = [3, 5, 2]
rails = ["HOL", "ELWRD", "LO"]
positions = [0, 0, 0]  # initially
result = "HELLOWORLD"  # at the end
תשובה אפשריתהטקסט המוצפן מורכב ממחרוזות שורות מחוברות ללא מפרידים. הספירה מאפשרת לזהות את גבולות כל שורה.
מתכנתים | Python
שלוש פונקציות: בניית מסלול משותף, הצפנה ופענוח. ההערות בקוד מסבירות את פעולת כל שלב; ההסברים בעברית מופיעים מתחת לקוד.
def path(length, n):
    # Validate the number of rails
    if n < 2:
        raise ValueError('n must be at least 2')
    row, direction = 0, 1  # Start at the top, moving down
    result = []  # Row number for each character
    for _ in range(length):
        result.append(row)  # Record the current row
        if row == 0:
            direction = 1  # Top: move down
        elif row == n - 1:
            direction = -1  # Bottom: move up
        row += direction  # Move to the next row
    return result

def encrypt(text, n):
    route = path(len(text), n)  # Build and validate route
    rails = [''] * n  # One empty string per row
    for char, row in zip(text, route):
        rails[row] += char  # Add character to its row
    return ''.join(rails)  # Read rows from top to bottom

def decrypt(cipher, n):
    route = path(len(cipher), n)  # Rebuild original route
    counts = [route.count(r) for r in range(n)]  # Row sizes
    rails = []
    start = 0  # First unread ciphertext position
    for count in counts:
        rails.append(cipher[start:start + count])  # Extract row
        start += count  # Advance to next row boundary
    positions = [0] * n  # Next unread index in each row
    result = ''
    for r in route:
        index = positions[r]  # Read position in selected row
        result += rails[r][index]  # Recover next character
        positions[r] += 1  # Advance only this row
    return result

הרחבה: הפתרון המקורי עם iter ו־next
כל איטרטור שומר בעצמו את מיקום הקריאה. next מחזיר את התו הבא ומקדם את האיטרטור; לכן אין צורך ברשימת positions.
def decrypt_iter(cipher, n):
    route = path(len(cipher), n)
    counts = [route.count(r) for r in range(n)]
    rails = []
    start = 0
    for count in counts:
        rails.append(iter(cipher[start:start + count]))
        start += count
    return ''.join(next(rails[r]) for r in route)
