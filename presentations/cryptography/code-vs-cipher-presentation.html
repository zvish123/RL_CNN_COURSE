הגדרה ראשונה

קוד (Code)

קוד הוא מיפוי שרירותי בין ביטויים (מילים, משפטים) לבין משמעויות - מבוסס על "מילון" מוסכם מראש (codebook), ולא על נוסחה. כדי לדעת מה ביטוי מסוים אומר - חייבים לדעת את המילון. אין דרך "לחשב" את זה.

דוגמאות נוספות

עוד דוגמאות לקוד

  • שמות קוד למבצעים צבאיים (למשל "אור ירוק")
  • קוד מוסר - ייצוג של אותיות בצלילים, שנקרא היסטורית "קוד"
  • מילות מעבר מוסכמות מראש בין שני צדדים

קוד מוסר בעצם לא מתאים בול לאף אחת מההגדרות: מבנית הוא שיטתי - טבלה קבועה אחת (A=נקודה-קו, B=קו-נקודה-נקודה-נקודה...) שמאפשרת לייצג כל הודעה אפשרית, לא רק רשימה סגורה - ובזה הוא דומה יותר לצופן. הוא נקרא "קוד" בעיקר מוסכמה היסטורית (המינוח נקבע במאה ה-19, לפני שההבחנה הקריפטוגרפית המדויקת קוד/צופן התגבשה).

ההבדל האמיתי: קוד מוסר לא נועד לסודיות בכלל - הטבלה פומבית וידועה לכולם. המטרה שלו היא ייצוג (המרה בין טקסט לאותות קוליים/חשמליים), לא הסתרה. הוא קרוב יותר במהותו ל-ASCII או לברייל - שיטת קידוד (encoding) לצורך תעבורה, לא מנגנון אבטחה. שווה לדון בכיתה: אם תלמיד יטען שזה בעצם צופן ולא קוד - הטענה שלו מבוססת.

אבל מה אם...

מה אם רוצים להצפין הודעה חדשה?

מילון קוד עובד מצוין למספר קטן של ביטויים מוסכמים מראש. אבל מה אם המפקד צריך לשדר משפט חדש, שלא הוגדר מראש במילון? צריך שיטה שיטתית שעובדת על כל הודעה אפשרית - לא רק על רשימה סגורה.

הגדרה שנייה

צופן (Cipher)

צופן הוא אלגוריתם שיטתי שממיר כל אות/תו בהודעה לפי כלל מתמטי קבוע ומפתח (key) - כך שניתן להצפין כל הודעה אפשרית, לא רק ביטויים שהוגדרו מראש.

דוגמה קלאסית

צופן קיסר (Caesar Cipher)

הצופן הקלאסי הפשוט ביותר: מזיזים כל אות ב-k מקומות באלף-בית (מפתח = k).

E(x) = (x + k) mod 26

דוגמה

נראה איך זה עובד

A → D    T → W

עם מפתח k=3:

ATTACK  →  DWWDFN

הכיוון ההפוך

איך מפענחים בחזרה?

D(x) = (x - k) mod 26

מי שיודע את k יכול לפענח כל הודעה - זה בדיוק מה שהופך את זה לצופן ולא לקוד: יש נוסחה אחת שעובדת על כל טקסט.

הדגמת קוד · Python

מימוש צופן קיסר

def caesar_encrypt(text, key):
    result = ""
    for ch in text:
        if ch.isalpha():
            base = ord('A') if ch.isupper() else ord('a')
            result += chr((ord(ch) - base + key) % 26 + base)
        else:
            result += ch
    return result

def caesar_decrypt(text, key):
    return caesar_encrypt(text, -key)

msg = "ATTACK AT DAWN"
enc = caesar_encrypt(msg, 3)
print("מוצפן:", enc)                     # DWWDFN DW GDZQ
print("פוענח:", caesar_decrypt(enc, 3))  # ATTACK AT DAWN

כי אין כאן שום מילון של ביטויים מוגדרים מראש - הפונקציה עובדת על כל טקסט שנרצה, כל עוד יודעים את המפתח k. זה בדיוק ההבדל מהמילה "להפוך את הקערה" ששרירותית לגמרי ולא נגזרת מנוסחה.
