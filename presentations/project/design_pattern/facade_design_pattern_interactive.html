08 • Python

מחלקות השירות — בסיס התרגול

class AuthService:
    def verify(self, user):
        if not user:
            raise PermissionError("Missing user")

class FileValidator:
    def validate(self, filename, data):
        if not filename or not data:
            raise ValueError("Invalid file")

class StorageService:
    def save(self, filename, encrypted):
        print("Stored:", filename)
מה עדיין חסר?

שירות הצפנה ושירות רישום אירועים. לצורך דוגמת הלימוד נשתמש בשירותים מדומים — לא בהצפנה אמיתית.

09 • Python

מימוש ה־Facade

class SecureVaultFacade:
    def __init__(self, auth, validator, encryption, storage, logger):
        self.auth = auth
        self.validator = validator
        self.encryption = encryption
        self.storage = storage
        self.logger = logger

    def upload_file(self, user, filename, data):
        self.auth.verify(user)
        self.validator.validate(filename, data)
        encrypted = self.encryption.encrypt(data)
        self.storage.save(filename, encrypted)
        self.logger.log(user, "UPLOAD")
        return True

מה יתרון הזרקת השירותים ב־__init__?

אתגר: VaultFacade בפרויקט הגמר

תכננו Facade למערכת שרת–לקוח עם השירותים UserManager, PermissionManager, FileRepository, EncryptionManager, EventLogger.

vault.upload(user, filename, data)
vault.download(user, filename)
vault.share(user, filename, target_user)

משימות: שרטטו תרשים מחלקות, הגדירו אחריות לכל שירות, כתבו Facade ובדקו לפחות שני כישלונות.

רמז ראשון

כל פעולה ב־Facade תתאם כמה שירותים; בדיקות הרשאות יישארו ב־PermissionManager.

שלד פתרון
class VaultFacade:
    def __init__(self, permissions, files, encryption, logger):
        self.permissions = permissions
        self.files = files
        self.encryption = encryption
        self.logger = logger

    def download(self, user, filename):
        self.permissions.require_read(user, filename)
        encrypted = self.files.read(filename)
        data = self.encryption.decrypt(encrypted)
        self.logger.log(user, "DOWNLOAD")
        return data

זהו שלד רעיוני בלבד; יש להשלים שירותים, הרשאות, טיפול בשגיאות ואבטחה.
