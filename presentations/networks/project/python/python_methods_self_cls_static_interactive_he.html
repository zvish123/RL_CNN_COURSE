02 • מתודת מופע

מתודה רגילה: self

self מפנה לאובייקט המסוים שעליו הופעלה המתודה. השם self הוא מוסכמה חזקה; אינו מילת מפתח בפייתון.

class Client:
    def __init__(self, name):
        self.name = name
        self.connected = True

    def disconnect(self):
        self.connected = False

alice = Client("Alice")
alice.disconnect()
print(alice.connected)  # False
משתמשים במתודת מופע כאשר צריך לקרוא או לשנות מצב של אובייקט מסוים.

04 • מאחורי הקלעים

מה מועבר ל־self?

alice.disconnect()

בקירוב, זו צורת קריאה שקולה:

Client.disconnect(alice)

פייתון קושר מתודת מופע לאובייקט, ומעביר אותו כארגומנט הראשון.

05 • מתודת מחלקה

@classmethod ו־cls

מתודת מחלקה מקבלת את המחלקה עצמה בארגומנט הראשון. מקובל לקרוא לו cls.

class Client:
    active_count = 0

    def __init__(self, name):
        self.name = name
        Client.active_count += 1

    @classmethod
    def get_active_count(cls):
        return cls.active_count

alice = Client("Alice")
bob = Client("Bob")
print(Client.get_active_count())  # 2
זו דוגמה לימודית פשוטה: במערכת אמיתית צריך גם להפחית את המונה כשהלקוח מתנתק, ולטפל בגישה מקבילית אם יש Thread-ים.
06 • מתי cls שימושי במיוחד?

בניית אובייקט בדרך חלופית

@classmethod מתאימה ל־Factory Method — יצירת מופע מתוך פורמט אחר.

class Client:
    def __init__(self, name, port):
        self.name = name
        self.port = port

    @classmethod
    def from_text(cls, text):
        name, port = text.split(":")
        return cls(name, int(port))

client = Client.from_text("Alice:8080")
print(client.port)  # 8080
יתרון חשוב: cls(...) יוצר מופע גם של תת־מחלקה כאשר המתודה נקראת דרכה.
07 • מתודה סטטית

@staticmethod — כלי עזר שקשור למחלקה

מתודה סטטית אינה מקבלת self או cls באופן אוטומטי.

class Protocol:
    @staticmethod
    def encode_length(length):
        if not 0 <= length <= 9999:
            raise ValueError("Invalid length")
        return f"{length:04d}".encode("ascii")

print(Protocol.encode_length(150))
# b'0150'
הפעולה תלויה רק בפרמטר length, לא במצב של פרוטוקול מסוים ולא במצב המחלקה.
08 • דוגמה מפרויקט הכספת

למה __recv_exact יכולה להיות סטטית?

class Protocol:
    @staticmethod
    def __recv_exact(sock, n):
        buf = b""
        while len(buf) < n:
            chunk = sock.recv(n - len(buf))
            if not chunk:
                return None
            buf += chunk
        return buf

הפונקציה מקבלת את כל מה שהיא צריכה: sock ו־n. היא אינה קוראת מ־self או מ־cls.

שני קווים תחתונים בתחילת השם (__recv_exact) גורמים ל־Name Mangling. זו תכונה נפרדת לגמרי מסוג המתודה.

11 • איתור שגיאה

איזה קוד יגרום לשגיאה?

class Client:
    def __init__(self, name):
        self.name = name

    @staticmethod
    def display_name():
        return self.name
אין למתודה סטטית פרמטר בשם self. בפונקציה זו תתקבל NameError כאשר קוראים לה, משום ש־self לא מוגדר.
def display_name(self):
    return self.name

כאן המתודה חייבת לדעת לאיזה לקוח היא שייכת.

13 • שאלה מתקדמת

האם תמיד נכון להוסיף @staticmethod?

יש לכם פונקציה שמחשבת מרחק בין שתי נקודות, ואינה משתמשת במופע או במחלקה:

def distance(x1, y1, x2, y2):
    return ((x2-x1)**2 + (y2-y1)**2)**0.5
לא בהכרח. אם הפעולה חלק מהאחריות הלוגית של מחלקה, מתודה סטטית יכולה להתאים. אם זו פעולה כללית שאינה שייכת למחלקה מסוימת, עדיף לעיתים להשאיר אותה כפונקציה רגילה במודול.

15 • אתגר מסכם

תכננו מחלקת NetworkClient

לכל פעולה הבאה בחרו סוג מתודה והסבירו מדוע:

  1. שינוי כתובת השרת של לקוח מסוים.
  2. יצירת לקוח מתוך המחרוזת "Dana:9000".
  3. המרת אורך הודעה ל־4 ספרות ASCII עם אפסים מובילים.
class NetworkClient:
    def __init__(self, name, port):
        self.name = name
        self.port = port

    def change_port(self, port):
        self.port = port

    @classmethod
    def from_text(cls, text):
        name, port = text.split(":")
        return cls(name, int(port))

    @staticmethod
    def encode_length(length):
        if not 0 <= length <= 9999:
            raise ValueError("Invalid length")
        return f"{length:04d}".encode("ascii")

1 — self כי משנים מופע; 2 — cls כי יוצרים מופע; 3 — סטטית כי הקלט מספיק לביצוע הפעולה.

כרטיס יציאה

הסבירו במילים שלכם: מדוע המתודה Protocol.__recv_exact(sock, n) יכולה להיות סטטית? ומה צריך להשתנות כדי שהיא תהיה מתודת מופע?

היא פועלת רק על הארגומנטים שקיבלה ואינה תלויה במצב אובייקט. כדי שתהיה מתודת מופע בעלת הצדקה, אפשר לשמור את הסוקט ב־self.sock ולממש def recv_exact(self, n) — במקרה זה היא פועלת על הסוקט של המופע.
