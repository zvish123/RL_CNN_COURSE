מהדפדפן לשרת

לומדים HTTP, REST API, ספריית requests ו־JSON — צעד אחר צעד, גם ללא ידע מוקדם בנושא

בסיום השיעור תוכלו לכתוב תוכנת Python שמבקשת שירות משרת, מקבלת תשובת JSON ומעבדת אותה.

1מה קורה כשאתם לוחצים על כפתור באתר?

כשאתם משתמשים במכונת ההצפנה, הדפדפן שלכם אינו מבצע בהכרח את ההצפנה בעצמו. הוא שולח בקשה לשרת, והשרת מחזיר תשובה.

💻 לקוח (Client)
דפדפן או Python
בקשה ←
→ תשובה
🖥️ שרת (Server)
מכונת ההצפנה

HTTP הוא פרוטוקול שמגדיר כיצד לקוחות ושרתים שולחים בקשות ותשובות. לכל בקשה יש שיטה (Method), כתובת, ולעיתים פרמטרים. לתשובה יש קוד מצב (Status Code) ותוכן.

GET

בקשה לקבלת מידע או תוצאה. במכונת ההצפנה שלנו GET מפעיל את פעולת ההצפנה.

200 OK

הבקשה הצליחה.

400 Bad Request

השרת לא יכול לטפל בבקשה בגלל קלט לא תקין.

404 Not Found

הנתיב המבוקש אינו קיים בשרת.

שימו לב: localhost פירושו המחשב שבו התוכנית רצה. במעבדת מחשבים יש להשתמש בכתובת ה־IP של מחשב המורה, ולא ב־localhost של התלמיד.

2מהו API ומהו REST API?

API (Application Programming Interface) הוא ממשק מוסכם שמאפשר לתוכנה לבקש פעולות או מידע מתוכנה אחרת. כמו תפריט במסעדה: הלקוח יודע מה אפשר להזמין, בלי לדעת כיצד המטבח עובד.

REST הוא סגנון ארכיטקטוני לתכנון שירותי רשת. ב־REST משתמשים בכתובות URL לזיהוי משאבים ובשיטות HTTP כגון GET, POST, PUT/PATCH ו־DELETE כדי לבצע פעולות. REST API הוא API שנבנה בהתאם לעקרונות REST, כגון ממשק אחיד ובקשות עצמאיות (Stateless).

שיטהשימוש נפוץ
GETקריאת מידע
POSTיצירת משאב או שליחת מידע לעיבוד
PUTהחלפת ייצוג משאב
PATCHעדכון חלקי
DELETEמחיקת משאב
דיוק חשוב: השרת של אתגר ההצפנה מספק HTTP API פשוט עם הנתיב /encrypt. הוא מתאים ללימוד קריאות API, אך אינו דוגמה מלאה לתכנון RESTful לפי כל העקרונות.

מפרט ה־API של מכונת ההצפנה

GET http://SERVER_IP:8000/encrypt?text=hello&team=group1

הנתיב /encrypt נקרא Endpoint. הפרמטר text מכיל את הטקסט להצפנה ו־team מכיל את שם הקבוצה. השרת מקבל עד 200 תווים בטקסט של כל בקשה.

3איך שולחים בקשה מתוך Python?

ספריית requests מאפשרת לתוכנית Python לתקשר עם שרתי HTTP. אם הספרייה אינה מותקנת, אפשר להתקין אותה במסוף סביבת העבודה באמצעות הפקודה הבאה:

python -m pip install requests

דוגמה ראשונה: בקשת הצפנה

import requests

url = "http://localhost:8000/encrypt"
params = {"text": "hello", "team": "group1"}

response = requests.get(url, params=params, timeout=10)
response.raise_for_status()
data = response.json()

print(data["encrypted"])
שורה / פעולההסבר
import requestsטעינת הספרייה
paramsמילון פרמטרים; הספרייה מקודדת אותם לכתובת באופן תקין
requests.get(...)שליחת בקשת GET
timeout=10הגבלת משך ההמתנה לתשובה
raise_for_status()יצירת חריגה אם התקבלה שגיאת HTTP
response.json()פענוח גוף התשובה כ־JSON והחזרת אובייקט Python
data["encrypted"]גישה לשדה התוצאה מתוך המילון
השרת בוחר באופן אקראי ייצוגים להצפנה. לכן שתי בקשות עם אותו טקסט עשויות להחזיר פלט שונה. אין זו בהכרח תקלה.

4מהו JSON?

JSON (JavaScript Object Notation) הוא פורמט טקסט מוסכם להעברת נתונים. הוא אינו שפת תכנות. אפשר לייצג בו אובייקטים, מערכים, מחרוזות, מספרים, ערכי אמת/שקר ו־null.

טקסט JSON
{"team":"alpha","score":10}

טקסט שמייצג אובייקט.

מילון Python
{"team": "alpha", "score": 10}

אובייקט Python שניתן לגשת לשדותיו.

המרות בין טקסט JSON לאובייקטים בפייתון

import json

# טקסט JSON -> מילון Python
text = '{"team": "alpha", "score": 10}'
data = json.loads(text)
print(data["team"])  # alpha

# מילון Python -> טקסט JSON
result = {"ok": True, "count": 3}
json_text = json.dumps(result, ensure_ascii=False)
print(json_text)  # {"ok": true, "count": 3}
json.loads()

מפרש מחרוזת JSON ומחזיר מבנה נתונים של Python.

json.dumps()

ממיר מבנה נתונים של Python למחרוזת JSON.

response.json()

מפרש את גוף תשובת ה־HTTP כ־JSON. אין צורך לקרוא אחריו שוב ל־json.loads() על אותו מילון.

ההבדל החשוב: טקסט שנראה כמו רשימה אינו רשימה

import json

value = "[12,3]"      # str
numbers = json.loads(value)  # list
print(numbers[0])      # 12

# אבל פלט ההצפנה הוא מחרוזת עם זוגות רבים:
encrypted = "[12,3] [45,1]"
parts = encrypted.split()    # ["[12,3]", "[45,1]"]
first_pair = json.loads(parts[0])  # [12, 3]

המחרוזת "[12,3] [45,1]" אינה JSON תקין כמכלול: אלה שני מערכים המופרדים ברווח. לכן יש לפצל אותה לפני שמנסים לפרש כל זוג בנפרד.

6מיישמים בפייתון – משימות מדורגות

משימה 1: תקשורת

כתבו תוכנית ששולחת את המילה hello לשרת ומדפיסה את השדה encrypted. ודאו שהכתובת מתאימה למחשב שמריץ את השרת.

משימה 2: קלט משתמש

שנו את התוכנית כך שתבקש מהמשתמש טקסט ושם קבוצה. השתמשו בפרמטרים של requests, ולא בשרשור ידני של כתובת URL.

משימה 3: ניתוח פלט

הפרידו את התוצאה המוצפנת לזוגות. המירו כל זוג למבנה נתונים מתאים והציגו כמה זוגות התקבלו.

משימה 4: אמינות

טפלו בשגיאת חיבור, בזמן המתנה ארוך ובקוד HTTP שאינו מציין הצלחה. בדקו מה קורה כאשר השרת אינו פועל.
