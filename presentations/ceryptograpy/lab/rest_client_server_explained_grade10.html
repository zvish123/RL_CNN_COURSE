1. מטרות הלמידה

בסיום הפעילות תדעו להגדיר שירות API, להסביר את מסלול הבקשה והתשובה, לקרוא ולשנות קוד שרת ולקוח, ולבדוק תרחישים תקינים ושגויים.

שרת

ממתין לבקשות, מזהה נתיב, מפעיל פונקציה ומחזיר תשובה.

לקוח

שולח בקשה לכתובת URL, קורא את התשובה ומציג אותה.

REST API

ממשק מבוסס HTTP המאפשר לתוכנות לפנות לשירות דרך נתיבים מוגדרים.

נשתמש בהצפנת קיסר כי האלגוריתם מוכר; המטרה החדשה היא ללמוד תקשורת בין תוכניות, לא לפצח את הצופן המורכב של פרויקט החקר.

4. קוד השרת המלא – server.py

השרת משתמש רק בספריות המובנות של Python. העתיקו את הקוד לקובץ בשם server.py.

from http.server import HTTPServer, BaseHTTPRequestHandler
from urllib.parse import urlparse, parse_qs
import json


def caesar_encrypt(text, shift):
    result = ""
    for char in text:
        if 'a' <= char <= 'z':
            result += chr((ord(char) - ord('a') + shift) % 26 + ord('a'))
        elif 'A' <= char <= 'Z':
            result += chr((ord(char) - ord('A') + shift) % 26 + ord('A'))
        else:
            result += char
    return result


class MyHandler(BaseHTTPRequestHandler):
    def send_json(self, data, status_code=200):
        body = json.dumps(data).encode('utf-8')
        self.send_response(status_code)
        self.send_header('Content-Type', 'application/json; charset=utf-8')
        self.send_header('Content-Length', str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        parsed_url = urlparse(self.path)
        path = parsed_url.path
        params = parse_qs(parsed_url.query)

        if path == '/status':
            self.send_json({'status': 'running'})
        elif path == '/encrypt':
            text = params.get('text', [''])[0]
            shift_text = params.get('shift', ['3'])[0]
            try:
                shift = int(shift_text)
            except ValueError:
                self.send_json({'error': 'shift must be an integer'}, 400)
                return
            if not text:
                self.send_json({'error': 'text is required'}, 400)
                return
            encrypted = caesar_encrypt(text, shift)
            self.send_json({'original': text, 'encrypted': encrypted, 'shift': shift})
        else:
            self.send_json({'error': 'Endpoint not found'}, 404)


if __name__ == '__main__':
    server = HTTPServer(('127.0.0.1', 8000), MyHandler)
    print('Server running on http://127.0.0.1:8000')
    server.serve_forever()

פירוק הקוד לחלקים

רכיבמה הוא עושה?
HTTPServerמאזין לבקשות HTTP בכתובת ובפורט שנבחרו.
BaseHTTPRequestHandlerמחלקת בסיס שממנה יורשים כדי להגדיר איך לטפל בבקשות.
caesar_encrypt(text, shift)פונקציה עצמאית שמזיזה אותיות באנגלית ושומרת רווחים וסימנים.
do_GET(self)נקראת על ידי התשתית כשמגיעה בקשת GET.
urlparse(self.path)מפריד בין הנתיב לבין מחרוזת הפרמטרים.
parse_qs(...)יוצר מילון שבו לכל פרמטר רשימת ערכים; לכן משתמשים ב־[0].
send_json(...)ממיר מילון למחרוזת JSON, מקודד לבתים ושולח תשובת HTTP.
serve_forever()מפעיל לולאת טיפול בבקשות עד שעוצרים את השרת.

איך נשלחת תשובת JSON?

  1. json.dumps(data) ממיר מילון Python למחרוזת JSON.
  2. .encode('utf-8') ממיר את המחרוזת לבתים.
  3. send_response שולח קוד מצב, ו־send_header שולח כותרות.
  4. end_headers() מסיים את הכותרות.
  5. wfile.write(body) שולח את גוף התשובה.

ההפרדה החשובה: caesar_encrypt אינה מכירה HTTP. אפשר לבדוק אותה בנפרד מהשרת.

5. קוד הלקוח המלא – client.py

הלקוח משתמש בספריית requests, אותה יש להתקין בנפרד.

import requests

BASE_URL = 'http://127.0.0.1:8000'

try:
    response = requests.get(f'{BASE_URL}/status', timeout=5)
    response.raise_for_status()
    print('Server status:', response.json())

    response = requests.get(
        f'{BASE_URL}/encrypt',
        params={'text': 'Hello World', 'shift': 3},
        timeout=5
    )
    response.raise_for_status()
    data = response.json()
    print('Original:', data['original'])
    print('Encrypted:', data['encrypted'])
    print('Shift:', data['shift'])
except requests.RequestException as exc:
    print('Request failed:', exc)
שורה / פעולההסבר
requests.get(...)שולחת בקשת GET לשרת.
params={...}בונה פרמטרים בכתובת בצורה בטוחה, כולל קידוד רווחים ותווים מיוחדים.
timeout=5מגביל את זמן ההמתנה כדי שהתוכנית לא תיתקע ללא הגבלה.
raise_for_status()מעלה חריגה אם התקבלה תשובת שגיאה, למשל 400 או 404.
response.json()מפענחת את גוף תשובת JSON ומחזירה מילון Python.
except requests.RequestExceptionמטפלת בשגיאות תקשורת ובשגיאות HTTP שזוהו.

חשוב: response.json() לא מצפינה טקסט; היא רק קוראת ומפענחת את פורמט התשובה.

8. תרגול ובדיקת הבנה

משימה א׳ – ניתוח קוד

מדוע בשרת משתמשים ב־params.get('shift', ['3'])[0] ולא פשוט ב־params['shift']?

משימה ב׳ – קוד שגיאה

איזה קוד HTTP מתאים לבקשה /encrypt?text=abc&shift=xyz?

משימה ג׳ – קודם מתכננים, אחר כך מתכנתים

תכננו שירות חדש: GET /decrypt?text=khoor&shift=3. כתבו קלט, פלט ופסאודו־קוד, ואז מימשו את הנתיב בשרת.

רמז לאחר ניסיון עצמאי

הפונקציה caesar_encrypt כבר יודעת להזיז אותיות. מה יקרה אם תעבירו לה -shift?

משך מומלץ: 60 דקות, או שני חלקים בשיעור של 45 דקות. אם הזמן קצר, אפשר לתת את משימת הפענוח כהמשך בבית.

מגבלות אבטחה: http.server מתאים להדגמה ולמעבדה, לא לשרת ייצור. הדוגמה מאזינה רק ל־127.0.0.1, אינה כוללת TLS, אימות משתמשים או הגנות עומס. אין לחשוף אותה לאינטרנט.

חיבור לפרויקט חקר הצופן: אחרי שהתלמידים מבינים את השרת הפשוט, השוו בין /encrypt בדוגמה זו לבין /encrypt בשרת הפרויקט. השוו פרמטרים ו־JSON בלי לחשוף את אלגוריתם ההצפנה הסודי.
