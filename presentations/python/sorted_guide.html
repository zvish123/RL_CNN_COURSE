sorted()

המדריך המלא למיון רשימות בפייתון

🎯 מיון בסיסי

הפונקציה sorted() מקבלת רשימה ומחזירה רשימה חדשה ממוינת:

numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers)
print(sorted_numbers)
# תוצאה: [1, 2, 5, 8, 9]
מה קורה כאן?
Python ממיינת את המספרים מהקטן לגדול באופן אוטומטי. הרשימה המקורית numbers נשארת ללא שינוי, והפונקציה יוצרת רשימה חדשה ממוינת.

🔑 הפרמטר המיוחד: key

הפרמטר key הוא המפתח לכוח האמיתי של sorted(). הוא מאפשר לנו לקבוע לפי איזה קריטריון למיין את הרשימה.

דוגמה 1: מיון לפי אורך מחרוזת

words = ["apple", "banana", "kiwi", "watermelon"]
sorted_by_length = sorted(words, key=len)
print(sorted_by_length)
# result: ['kiwi', 'apple', 'banana', 'watermelon']
איך זה עובד?
הפונקציה len() מחזירה את אורך כל מילה:
• "kiwi" = 4 אותיות
• "apple" = 5 אותיות
• "banana" = 6 אותיות
• "watermelon" = 10 אותיות

Python ממיינת לפי המספרים האלה: 4, 5, 6, 10 ✨
sorted(words, key=len)
sorted(words, key=len())

שימו לב: כותבים key=len בלי סוגריים!

דוגמה 2: מיון לפי הספרה האחרונה

def last_digit(num):
    return num % 10

numbers = [45, 23, 78, 91, 12]
sorted_nums = sorted(numbers, key=last_digit)
print(sorted_nums)
# result: [91, 12, 23, 45, 78]
הסבר שלב אחר שלב:
1. הפונקציה last_digit מחזירה את הספרה האחרונה (שארית בחלוקה ב-10)
2. Python מפעילה את הפונקציה על כל מספר:
• 45 → 5
• 23 → 3
• 78 → 8
• 91 → 1
• 12 → 2
3. מיון לפי הספרות: 1, 2, 3, 5, 8
4. result: [91, 12, 23, 45, 78] 🎉

דוגמה 3: מיון תלמידים לפי ציון

def get_grade(student):
    return student['grade']

students = [
    {'name': 'דני', 'grade': 85},
    {'name': 'מיכל', 'grade': 92},
    {'name': 'רון', 'grade': 78}
]

sorted_students = sorted(students, key=get_grade)
print(sorted_students)
# מיון מהציון הנמוך לגבוה: רון (78), דני (85), מיכל (92)
מיון מבני נתונים מורכבים:
כל תלמיד הוא מילון עם שדות name ו-grade. הפונקציה get_grade "מוציאה" את הציון מכל תלמיד, ו-Python ממיינת לפי הציונים. זה מאוד שימושי כשעובדים עם נתונים מורכבים! 📊

🔄 מיון הפוך עם reverse=True

רוצים למיין מהגדול לקטן? פשוט הוסיפו reverse=True:

numbers = [5, 2, 8, 1, 9]
sorted_desc = sorted(numbers, reverse=True)
print(sorted_desc)
# result: [9, 8, 5, 2, 1]

שילוב key ו-reverse

words = ["apple", "banana", "kiwi", "watermelon"]
sorted_by_length_desc = sorted(words, key=len, reverse=True)
print(sorted_by_length_desc)
# result: ['watermelon', 'banana', 'apple', 'kiwi'] - מהארוך לקצר!

💡 טיפים חשובים לזכור

  • הפונקציה ב-key לא מקבלת סוגריים - כותבים key=len ולא key=len()
  • הפונקציה מחזירה ערך למיון, לא משנה את האובייקט המקורי
  • sorted() יוצרת רשימה חדשה - הרשימה המקורית נשארת ללא שינוי
  • אפשר לשלב key ו-reverse ביחד לקבלת שליטה מלאה על המיון
  • כל פונקציה שמחזירה ערך ניתן להשוואה יכולה לשמש כ-key
