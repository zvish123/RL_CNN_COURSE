02 / הגדרה

מה זה Brute Force?

שיטה שבה מנסים אפשרויות רבות באופן שיטתי עד שמוצאים את הנכונה. באבטחת מידע מדובר לעיתים בניסיונות חוזרים לנחש סיסמת התחברות.

Brute Force

סיסמאות רבות מול חשבון מסוים.

Password Spraying

סיסמה נפוצה אחת מול חשבונות רבים.

Credential Stuffing

ניסיון שימוש בזוגות שם משתמש וסיסמה שנחשפו בעבר.

ההבדל חשוב: הגבלה לפי חשבון בלבד אינה עוצרת בהכרח ניסיונות מול חשבונות רבים.

07 / ארכיטקטורה

היכן מממשים את ההגנה?

Client → שולח בקשת LOGIN
NetworkServer → מזהה כתובת מקור אמינה מתוך חיבור ה־socket
LoginRateLimiter → בודק אם מותר לנסות להתחבר
AuthenticationManager → מאמת שם משתמש וסיסמה רק אם הבקשה מותרת
SecurityLogger → מתעד כישלון, חסימה או הצלחה

אין לסמוך על כתובת IP שהלקוח מדווח בעצמו בשדה של ההודעה.

08 / תכנון קוד

ממשק המחלקה לתלמיד

class LoginRateLimiter: def is_allowed(self, username, ip): ... def record_failure(self, username, ip): ... def record_success(self, username, ip): ... def cleanup(self): ...

אפשר להשתמש ב־defaultdict(deque) לשמירת ניסיונות וב־time.monotonic() למדידת מרווחי זמן. בשרת מרובה Threads יש להגן על פעולות הבדיקה והעדכון כמקשה אחת.

שניהם עלולים לקרוא מונה ישן ולהרשות ניסיונות נוספים. יש להשתמש ב־Lock או במנגנון אטומי משותף.
