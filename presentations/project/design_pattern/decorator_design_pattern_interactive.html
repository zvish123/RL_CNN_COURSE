4 · הרעיון של Decorator

Decorator היא תבנית מבנית (Structural Pattern) שמוסיפה אחריות או התנהגות לאובייקט באמצעות עטיפתו באובייקט אחר שמציג את אותו ממשק.

Client
←
LoggingDecorator
←
EncodingDecorator
←
BasicSender
כל שכבה יודעת להפעיל את אותה פעולה (`send`) על השכבה שהיא עוטפת. הלקוח אינו צריך לדעת כמה שכבות יש.

5 · מי משתתף בתבנית?

Component

הממשק המשותף: למשל `send(message)`.

ConcreteComponent

האובייקט הבסיסי: `BasicSender`.

Decorator

שומר הפניה לאובייקט מסוג Component ומעביר אליו קריאות.

ConcreteDecorator

מוסיף התנהגות: `LoggingDecorator`, `EncodingDecorator`.

מי אחראי לשליחת ההודעה בפועל?
`BasicSender`. ה־Decorators מעבדים או מתעדים, ואז מעבירים את הקריאה פנימה.

6 · ממשק משותף בפייתון

from abc import ABC, abstractmethod

class MessageSender(ABC):
    @abstractmethod
    def send(self, message: bytes) -> None:
        pass

class BasicSender(MessageSender):
    def send(self, message: bytes) -> None:
        print("Sending:", message)
למה גם Decorator צריך לממש את `MessageSender`?
כדי שהלקוח יוכל להשתמש באובייקט עטוף בדיוק כפי שהוא משתמש בשולח בסיסי — ללא שינוי בקוד הלקוח.

7 · מחלקת Decorator בסיסית

class SenderDecorator(MessageSender):
    def __init__(self, wrapped: MessageSender):
        self.wrapped = wrapped

    def send(self, message: bytes) -> None:
        self.wrapped.send(message)

Composition

האובייקט מחזיק אובייקט אחר בתכונה `wrapped`.

Delegation

הקריאה מועברת לשכבה הפנימית.

הדפוס משתמש בהרכבה, ולעיתים גם בירושה לצורך ממשק משותף.

8 · מוסיפים Logging

class LoggingDecorator(SenderDecorator):
    def send(self, message: bytes) -> None:
        print("LOG: Sending message")
        super().send(message)

9 · מוסיפים קידוד Hex

כדי להמחיש עיבוד מידע, נשתמש בקידוד Hex. זה אינו מנגנון הצפנה.

class EncodingDecorator(SenderDecorator):
    def send(self, message: bytes) -> None:
        encoded = message.hex().encode("ascii")
        super().send(encoded)

sender = EncodingDecorator(BasicSender())
sender.send(b"HI")
מה יתקבל ב־BasicSender?

11 · סימולציה: בונים צינור הודעות

בחרו שכבות, שנו את סדר הקידוד והדחיסה, וצפו בשלבים. הדחיסה בסימולציה משתמשת ב־zlib (בהדמיית גודל), והקידוד ב־Hex.

סדר העיבוד:

פלט מדומה

לחצו על הפעלת סימולציה.
הדוגמה מציגה עיבוד bytes ולא העברת רשת אמיתית. Hex מגדיל את נפח המידע; דחיסה אינה תמיד מקטינה נתונים קצרים.

13 · מה קורה בקריאה חוזרת?

בכספת קבצים צריך לתמוך גם ב־`load()` ולא רק ב־`save()`.

שמירה: דחיסה
←
הצפנה
←
אחסון
קריאה: פענוח
←
פריסה
←
המידע המקורי
כלל חשוב: אם בשמירה הפעלנו A ואז B, בשחזור נדרש להפעיל את ההיפוך של B ואז את ההיפוך של A. יש לתכנן ממשקי `save/load` תואמים.

16 · ומה עם @decorator בפייתון?

המונח Decorator מופיע גם בתחביר `@` בפייתון, לרוב לעטיפת פונקציות.

from functools import wraps

def log_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("Calling", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log_calls
def greet(name):
    print("Hello", name)

greet("Dana")
שני הרעיונות מבוססים על עטיפה והוספת התנהגות, אבל `@decorator` הוא מנגנון תחבירי של פייתון, ואילו Decorator Design Pattern היא תבנית ארכיטקטונית לאובייקטים בעלי ממשק משותף.

17 · אתגר יישום: כספת קבצים

בנו רכיבי אחסון שמאפשרים להוסיף שכבות של Logging, דחיסה והצפנה.

class FileStorage(ABC):
    @abstractmethod
    def save(self, filename: str, data: bytes): ...

    @abstractmethod
    def load(self, filename: str) -> bytes: ...
  1. ממשו `MemoryStorage` לשמירת bytes בזיכרון.
  2. ממשו `LoggingStorageDecorator`.
  3. ממשו `CompressionStorageDecorator` עם `zlib`.
  4. הוסיפו שכבת הצפנה באמצעות ספרייה מאובטחת — הרחבה.
  5. בדקו ש־`load()` מחזירה בדיוק את הנתונים המקוריים.
מחלקת הבסיס של ה־Decorator מחזיקה `self.wrapped` ומממשת `save` ו־`load` באמצעות העברת הקריאה פנימה. כל שכבה משנה את המידע רק בנקודה הנכונה.

18 · פתרון מדורג לאתגר

נסו לפתור לפני חשיפת הקוד.

import zlib

class StorageDecorator(FileStorage):
    def __init__(self, wrapped: FileStorage):
        self.wrapped = wrapped

    def save(self, filename, data):
        self.wrapped.save(filename, data)

    def load(self, filename):
        return self.wrapped.load(filename)

class CompressionStorageDecorator(StorageDecorator):
    def save(self, filename, data):
        super().save(filename, zlib.compress(data))

    def load(self, filename):
        return zlib.decompress(super().load(filename))
class MemoryStorage(FileStorage):
    def __init__(self):
        self.files = {}

    def save(self, filename, data):
        self.files[filename] = data

    def load(self, filename):
        return self.files[filename]

class LoggingStorageDecorator(StorageDecorator):
    def save(self, filename, data):
        print("SAVE", filename)
        super().save(filename, data)

    def load(self, filename):
        print("LOAD", filename)
        return super().load(filename)

storage = LoggingStorageDecorator(
    CompressionStorageDecorator(MemoryStorage())
)
storage.save("a.txt", b"HELLO" * 10)
assert storage.load("a.txt") == b"HELLO" * 10
