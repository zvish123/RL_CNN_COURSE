יחידת לימוד 1 · HTTP ו־API

API הוא ממשק המאפשר לתוכנה אחת לבקש פעולה או מידע מתוכנה אחרת. HTTP הוא פרוטוקול תקשורת נפוץ בין לקוח לשרת. התוכנית שלכם היא הלקוח; מכונת ההצפנה היא השרת.

בקשה (Request)

הלקוח שולח כתובת, שיטת HTTP ופרמטרים.

תשובה (Response)

השרת מחזיר קוד מצב ונתונים.

מפרט API של מכונת ההצפנה

רכיבערך
MethodGET
Endpoint/encrypt
Parameterstext – טקסט להצפנה; team – שם קבוצה
Responseאובייקט JSON עם encrypted ו־id
מגבלת קלט200 תווים בבקשה; השרת אינו חותך את מחרוזת התוצאה ל־200 תווים

דוגמת כתובת מקומית: http://localhost:8000/encrypt?text=hello&team=group1. במחשב תלמיד יש להשתמש בכתובת ה־IP של שרת המורה במקום localhost.

יחידת לימוד 2 · JSON

JSON הוא פורמט טקסט לייצוג מידע מובנה. הוא תומך באובייקטים, מערכים, מחרוזות, מספרים, ערכים בוליאניים ו־null. ב־Python הספרייה json מאפשרת להמיר בין טקסט JSON לבין מבני נתונים.

{ "encrypted": "[12,3] [45,1]", "id": 7 }

בדוגמה, הערך של encrypted הוא מחרוזת, אף שבתוכה מופיעים זוגות שנראים כמו רשימות. הערך של id הוא מספר. זו דוגמה למבנה התשובה ולא לתוצאת הצפנה מסוימת.

מושגים ללמידה עצמית

json.loads() ממיר מחרוזת JSON לערך Python; json.dumps() ממיר ערך Python לטקסט JSON. לעומת זאת, response.json() של requests קורא ומפענח את גוף תשובת ה־HTTP כ־JSON.

יחידת לימוד 3 · requests

ספריית requests מאפשרת לשלוח בקשות HTTP מתוך Python. חקרו בתיעוד הספרייה את המושגים הבאים:

שליחת בקשה

requests.get שולחת בקשת GET; params מאפשרת להעביר פרמטרים בצורה מסודרת.

קריאת תשובה

response.json() קוראת תשובת JSON; status_code מציין את מצב הבקשה.

טיפול בשגיאות

raise_for_status() מאפשרת לזהות שגיאות HTTP; timeout מונע המתנה בלתי מוגבלת.

התקנה

יש לוודא ש־requests מותקנת בסביבת ה־Python של הפרויקט ב־PyCharm או ב־VS Code.

משימת תכנות 1 · לקוח הצפנה

כתבו בעצמכם תוכנית Python המבקשת טקסט מהמשתמש, שולחת אותו לשרת, קוראת את תשובת ה־JSON ומציגה את הפלט המוצפן. אל תתחילו עדיין בפענוח.

התוכנית מתחברת לכתובת שרת המורה, לא ל־localhost במחשב התלמיד
התוכנית שולחת את הפרמטרים text ו־team
התוכנית מפענחת את תשובת ה־JSON ומחלצת encrypted
התוכנית מטפלת בשגיאות HTTP ובשרת שאינו מגיב
התוכנית מוודאת שהקלט אינו ארוך מ־200 תווים

הצפנת אותו טקסט פעמיים עשויה להחזיר פלטים שונים. לכן אין לדרוש זהות בין התוצאות, אלא תקינות מבנית של הפלט ומספר היחידות המוחזרות עבור קלט מתאים.

משימת תכנות 2 · תכנון אלגוריתם לפענוח

חזרו לשיטת החקר הידנית שלכם. תכננו כיצד התוכנית תבצע ניסויים, תשמור תוצאות ותנסה לזהות התאמות. בחרו מבני נתונים המתאימים למידע שנאסף.
