⚙️ מערכת קליטת עובד חדש — PowerShell

פרויקט אישי: בניית סקריפט PowerShell שמאוטמט את תהליך קליטת עובדים חדשים בחברה — מקבלת פרמטרים ועד דוח סיכום מלא.

הרקע: חברת "TechStart Solutions" היא חברת פיתוח תוכנה עם 50 עובדים. כל חודש מצטרפים 2–3 עובדים חדשים, ואיש ה-IT מבלה כ־3 שעות על הכנת כל מחשב חדש. התהליך כולל יצירת תיקיות עבודה, העתקת קבצי תבנית, בדיקת קישוריות לשרתים, והכנת קבצי הדרכה.

הבעיה: התהליך הידני ארוך, משעמם, וגורם לאיש ה-IT לפספס לפעמים צעדים חשובים.
המשימה שלכם: לכתוב סקריפט PowerShell (Onboarding.ps1) שמקצר את התהליך מ־3 שעות ל־5 דקות — אוטומטית, בלחיצת כפתור.
לפני שמתחילים:
  • זהו פרויקט מסכם — משלב את כל מה שלמדתם: פרמטרים, משתנים, pipeline, קבצים ותיקיות, משתני סביבה, מבני בקרה, ואובייקטים.
  • עבדו ב-PowerShell ISE או VS Code, לא בקונסולה — תצטרכו לשמור, להריץ ולתקן שוב ושוב.
  • לפני ההרצה הראשונה — הכינו את קבצי הבסיס (ראו "הכנה לעבודה" בתחתית הדף).
  • בתחתית הדף תמצאו את מנגנון ההגשה — קראו את ההנחיות שם, יש בו הבהרה חשובה.
ניווט מהיר:
חלק א׳ — פרמטרים ומסך פתיחה (20) חלק ב׳ — מבנה תיקיות (25) חלק ג׳ — העתקת קבצי תבניות (20) חלק ד׳ — בדיקת קישוריות (20) חלק ה׳ — קובץ WELCOME (10) חלק ו׳ — דוח סיכום (15) חלק ז׳ — לוגים בסיסיים (10) טבלת ציונים הכנה לעבודה הגשה

$folderPath = ".\Work\$EmployeeName\Projects\Current"

4. העתקת קבצים לפי מחלקה

הנחה: בתיקייה .\Company\Templates\ יש תת-תיקייה לכל מחלקה: Development, Marketing, Sales, וגם General (קבצים לכולם).

משימתך:

טיפ 
$deptPath = ".\Company\Templates\$Department"
$destPath = ".\Work\$EmployeeName\Documents\Templates"

if (Test-Path $deptPath) {
    Copy-Item -Path "$deptPath\*" -Destination $destPath -Recurse -Force
} else {
    Write-Host "⚠ Warning: no templates found for department '$Department'" -ForegroundColor Yellow
}

Copy-Item -Path ".\Company\Templates\General\*" -Destination $destPath -Recurse -Force

$copiedCount = (Get-ChildItem -Path $destPath -Recurse -File).Count
Write-Host "Copied $copiedCount template files"

בדיקת קישוריות

20 נקודות
5. בדיקת חיבור לשרתים

קובץ company_servers.txt מכיל:

portal.techstart.local
files.techstart.local
mail.techstart.local

משימתך:

טיפ — ב-PowerShell משתמשים ב-Test-Connection ולא בקריאה ל-ping.exe 
$servers = Get-Content ".\company_servers.txt"
$results = @()
$accessibleCount = 0

foreach ($server in $servers) {
    if (Test-Connection -ComputerName $server -Count 1 -Quiet) {
        Write-Host "✓ $server - Accessible" -ForegroundColor Green
        $results += "✓ $server - Accessible"
        $accessibleCount++
    } else {
        Write-Host "✗ $server - NOT accessible" -ForegroundColor Red
        $results += "✗ $server - NOT accessible"
    }
}

$results | Out-File -FilePath ".\connectivity_report.txt"
Write-Host "Servers accessible: $accessibleCount / $($servers.Count)"

הכנה לעבודה

לפני שאתם מתחילים לכתוב את Onboarding.ps1, הכינו את סביבת הבדיקה:

1. צרו תיקיית תבניות
New-Item -Path ".\Company\Templates\Development" -ItemType Directory -Force
New-Item -Path ".\Company\Templates\Marketing" -ItemType Directory -Force
New-Item -Path ".\Company\Templates\Sales" -ItemType Directory -Force
New-Item -Path ".\Company\Templates\General" -ItemType Directory -Force
2. צרו קבצי דמה
Set-Content -Path ".\Company\Templates\Development\code_sample.py" -Value "Sample"
Set-Content -Path ".\Company\Templates\General\handbook.pdf" -Value "Sample"
3. צרו קובץ שרתים
Set-Content -Path ".\company_servers.txt" -Value @"
portal.techstart.local
files.techstart.local
mail.techstart.local
"@

קובץ עזר נוסף להתקנה ראשונית של הסביבה: environment_setup.ps1 (יימסר בנפרד אם צריך).
