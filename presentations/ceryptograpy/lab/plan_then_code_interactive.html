[8, 3, 15, 6, 11]

מה בדיוק תגידו לו לעשות? ״מצא את הגדול ביותר״ אינה הוראה מספיקה.

1. שמור את המספר הראשון כגדול ביותר. 2. עבור על יתר המספרים. 3. אם מספר גדול מהשמור — עדכן אותו. 4. הצג את המספר השמור.

מימוש ב־Python

numbers = [8, 3, 15, 6, 11] maximum = numbers[0] for number in numbers: if number > maximum: maximum = number print(maximum)

שימו לב: פסאודו־קוד מתאר את ההיגיון. Python מחייבת שמות משתנים, נקודתיים והזחות תקינות.

למורה: שאלו מה יקרה ברשימה ריקה. זהו תנאי קדם שהאלגוריתם חייב להגדיר או לטפל בו.

תרגיל: סדרו את שלבי האלגוריתם

למורה · 7 דקות: זו משימת תכנון בלבד; היא אינה חושפת כיצד בונים את טבלת ההתאמות של הצופן האמיתי.

מהפסאודו־קוד ל־Python

פסאודו־קוד

קבל זוגות מוצפנים וטבלת התאמות צור תוצאה ריקה עבור על כל זוג: אם הזוג נמצא בטבלה: הוסף את התו המתאים אחרת: הוסף ? הצג את התוצאה

קוד

mapping = {(12, 3): "a", (45, 1): "b"} pairs = [(12, 3), (45, 1), (99, 0)] result = "" for pair in pairs: if pair in mapping: result += mapping[pair] else: result += "?" print(result) # ab?

דוגמת תרגול בלבד: הטבלה נתונה מראש ואינה מייצגת פתרון לפיצוח הצופן.

בדיקת הבנה: מה קורה במקרה לא מוכר?

במילון קיימות ההתאמות (12,3) → a ו־(45,1) → b. התוכנית מקבלת גם (99,0).

מה תהיה התוצאה?
למורה: בקשו מהתלמידים לבצע מעקב ידני אחרי המשתנה result בכל איטרציה.
